本仓库仅保存可运行的 Web 导出包、许可证和版本凭据；源码仓库及其 Git 历史未同步到这里。Godot 导出包内含游戏运行所需的数据、脚本与素材。当前版本为六班试玩，面向桌面横屏浏览器。进度只保存在当前站点的浏览器本地存储中。

每班都有来袭前突发事件；选择后的回执与值班手册帮助理解跨班承诺和防线结果。旧版存档可继续原班次，从菜单重新开局可体验新增事件。
